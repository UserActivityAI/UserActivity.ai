# UserActivity.ai

AI-powered user activity analytics for understanding how people interact with your product.

**Live at [useractivity.ai](https://useractivity.ai)**

## About

UserActivity.ai provides intelligent analytics to help product teams understand user behavior patterns, identify engagement signals, and make data-driven decisions.

## Stack

- **Framework**: Next.js (App Router)
- **Database**: Supabase
- **Hosting**: Vercel
- **Styling**: Tailwind CSS
